NOTES
Config files under examples/custom_network/config_hpcc_case*.txt are base templates.
generate_custom_inputs.py rewrites TOPOLOGY_FILE, FLOW_FILE, TRACE_FILE, FCT_OUTPUT_FILE, REORDER_OUTPUT_FILE, other output paths, FLOW_STRATEGY, DEFAULT_FWD_MODE, monitor times, and ECN maps into generated/<name>/network_config.txt.
scenario.network.config_overrides can rewrite raw config keys such as ENABLE_PFC, ENABLE_QCN, ENABLE_RTO, WAIT_ACK_TIMEOUT, CC_MODE, ACK_HIGH_PRIO, and USE_DYNAMIC_PFC_THRESHOLD.
Use FLOW_STRATEGY 1 with DEFAULT_FWD_MODE 0 to exercise HPCC-Dev-style path pinning.
Use DEFAULT_FWD_MODE 1 to exercise packet spray; packet spray uses PACKET_STRATEGY 0=flow-base round-robin, 1=random, or 2=DLB least-queued half random.
For packet-spray receiver experiments, use OOO_RECEIVE_MODE 0 for the legacy unlimited buffer or 1 for finite OOO buffering with NACK/GBN recovery. OOO_BUFFER_SIZE is a per-Rx-QP payload-byte limit; an OOO packet that would exceed it is rejected, the cached OOO entries are flushed, and the existing NACK/GBN path starts recovery. During recovery, later OOO packets are discarded until the missing cumulative prefix arrives. Mode 2 is reserved and currently rejected by ns-3.
