NOTES
Config files under examples/custom_network/config_hpcc_case*.txt are base templates.
generate_custom_inputs.py rewrites TOPOLOGY_FILE, FLOW_FILE, TRACE_FILE, output paths, FLOW_STRATEGY, DEFAULT_FWD_MODE, monitor times, and ECN maps into generated/<name>/network_config.txt.
scenario.network.config_overrides can rewrite raw config keys such as ENABLE_PFC, ENABLE_QCN, CC_MODE, ACK_HIGH_PRIO, and USE_DYNAMIC_PFC_THRESHOLD.
Use FLOW_STRATEGY 1 with DEFAULT_FWD_MODE 0 to exercise HPCC-Dev-style path pinning.
Use DEFAULT_FWD_MODE 1 to exercise packet spray; packet spray uses PACKET_STRATEGY.
